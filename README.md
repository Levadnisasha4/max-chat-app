MAX Chat App (Тестовое задание)

Веб-приложение для отправки и получения текстовых сообщений в мессенджере MAX через сервис GREEN-API. 

Проект реализован на React + TypeScript + Vite с использованием минимального набора функций, повторяя внешний вид чата web.max.ru.

Требования

Перед запуском убедитесь, что на вашем компьютере установлен Node.js (версия 18 или выше). 
Если Node.js не установлен:
1. Перейдите на официальный сайт (https://nodejs.org/).
2. Скачайте и установите версию LTS.
3. Проверьте установку, выполнив в терминале команду:
   node -v
(Должна отобразиться версия, например: v20.11.0)

Установка и локальный запуск
Шаг 1. Скачивание проекта

git clone <ссылка_на_репозиторий>
cd max-chat-app
Если Git не установлен, просто скопируйте папку с проектом на свой компьютер и откройте терминал в этой папке.

Шаг 2. Установка зависимостей
В терминале, находясь в корневой папке max-chat-app, выполните команду:

npm install
Эта команда создаст папку node_modules и установит все необходимые библиотеки (React, Vite, TypeScript и т.д.).

Шаг 3. Запуск проекта
После успешной установки зависимостей запустите локальный сервер разработки:

npm run dev
В терминале появится ссылка, обычно это:

Local:   http://localhost:5173/
Откройте эту ссылку в вашем браузере.

Шаг 4. Сборка production-версии (опционально)
Если вам нужно собрать проект для размещения на хостинге, выполните:

npm run build
Готовые файлы появятся в папке dist.

Как пользоваться приложением
Вход: На странице входа введите ваши idInstance и apiTokenInstance из личного кабинета GREEN-API.

Создание чата: В боковой панели введите номер телефона получателя (например, 79991234567) и нажмите «Создать».

Примечание: Приложение автоматически добавит суффикс @c.us к номеру.

Отправка сообщения: Напишите текст в поле ввода внизу экрана и нажмите кнопку отправки.

Получение ответа: Когда получатель ответит вам в мессенджере MAX, его сообщение автоматически появится в окне чата (приложение опрашивает сервер каждые 1.5 секунды с помощью метода ReceiveNotification).

│   │   └── greenApi.ts      # Работа с методами GREEN-API (sendMessage, receiveNotification)

│   ├── types.ts             # TypeScript интерфейсы и типы

├── index.html               # HTML-шаблон
├── package.json             # Зависимости и скрипты
├── tsconfig.json            # Конфигурация TypeScript
├── tsconfig.node.json       # Конфигурация TypeScript для Vite
└── vite.config.ts           # Конфигурация Vite
